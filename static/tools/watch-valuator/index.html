▶ How this estimate is calculated

Formula: base reference × age factor × condition factor × completeness factor, then ±10% for the range. The age factor is set per brand retention tier — the higher the tier, the less time erodes value.

  • ARolex, Patek Philippe, Audemars Piguet, Vacheron Constantin, etc. — very strong resale retention; some models even hold a premium.
  • BOmega, Cartier, Tudor, IWC, etc. — moderate retention, gradual decline with age.
  • CTAG Heuer, Longines, Tissot, Seiko, etc. — entry-level brands that depreciate faster.
This is a rule-based heuristic model, not real-time market data — reference only, not a trade offer.
Actual retention varies with market supply/demand, limited editions, and scarcity — real transaction prices can differ significantly from this estimate.
